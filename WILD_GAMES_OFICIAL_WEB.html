📬 Cómo pedir acceso a WILD GAMES

La web no tiene un servidor independiente: el acceso se coordina directamente con la persona propietaria del mundo.

¿Quieres entrar al mundo? Envíame un correo indicando tu gamertag y que quieres recibir mi gamertag para añadirme como amigo y poder unirte cuando esté disponible.

¿Quieres solicitar un rango, enviar una sugerencia o informar de un error? Usa el formulario de solicitudes de arriba.

Aquí tienes mi correo:

INSERTAR_TU_CORREO_AQUÍ

Cambia el texto «INSERTAR_TU_CORREO_AQUÍ» por tu correo real. También debes poner ese mismo correo en la variable CONTACT_EMAIL del código para que el formulario funcione.
